# Peace Intel: lenses and the answer mode (exploration)

A staging copy of `handoff/lens-lab.html` from the Peace Intel design system, Revs 76 to 78
(5 November 2026), for review. Open `index.html`.

- **29 · Lens**: a reader can read the evidence through an organisation's or an expert's
  framework, per chat. One `.act` in the composer's bar raises a `.clarify` card from the
  composer; each lens has a switch (`.lens-sw`), a summary under its name, and its lens file
  (Markdown, formatted or raw, in a `.dlg`). A lens that is on is named in the control, in a
  line in the thread and in a tag over every answer.
- **30 · Answer mode**: the four-way mode tray becomes one control naming the mode, opening a
  radio card from the composer. No new CSS.

**Status: exploration.** Nothing here is agreed for production. The new CSS is in
`explorations.css` under "29 · LENS". The script at the foot of `index.html` is a mock to read
for behaviour; do not port it. Every framework text and every mode timing is sample text, and
Dr. Talia Mercer is a fictional placeholder. The rules for the system are in `handoff/AGENTS.md`.
